# One Emoji, One Smile

The entry is a single emoji: **🫶 (heart hands)**.

Why this emoji: it is warm and friendly at first glance — two hands shaping a heart — and a stranger of any age or background reads it the same way, with no irony or in-joke. It feels deliberately chosen rather than the default 🙂, yet stays instantly readable. And it is right for a stranger: it plainly aims to warm someone, with no intimacy (unlike 🤗), no sarcasm and no flirtation (unlike 🥰).

## How to run

```sh
node main.ts
```

This writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline and no extra whitespace — exactly the emoji bytes.
